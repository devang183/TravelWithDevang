# Trip Planner Features

## Overview
The CityMap component now includes a comprehensive trip planning system with day-wise itinerary management and PDF export functionality.

## Features Implemented

### 1. Trip Planning Modes

#### Single Day Trip
- Add places to a single itinerary by clicking on map markers
- Places are numbered sequentially (1, 2, 3, ...)
- Connected with a purple dotted line on the map
- Perfect for quick day trips or short visits

#### Multi-Day Trip
- Plan trips spanning 1-7 days
- Select number of days using the day selector
- Each day has its own itinerary tab
- Places are marked with day-specific numbers (D1-1, D1-2, D2-1, etc.)
- Each day uses a different color:
  - Day 1: Blue (#3b82f6)
  - Day 2: Green (#10b981)
  - Day 3: Amber (#f59e0b)
  - Day 4: Red (#ef4444)
  - Day 5: Purple (#8b5cf6)

### 2. User Interface

#### Mode Selection
- Toggle between "Single Day Trip" and "Multi-Day Trip" modes
- Clear visual indication of active mode

#### Day Configuration (Multi-Day Mode)
- Select number of days (1-7) with button controls
- Day tabs showing place count for each day
- Switch between days to add places to different days
- Current day is highlighted

#### Adding Places
- Click "Add to Trip Plan" button in any place's popup
- Places automatically added to:
  - Main itinerary (Single Day mode)
  - Currently selected day (Multi-Day mode)
- Duplicate detection prevents adding same place twice

#### Managing Places
- Remove individual places with X button
- Clear entire day's itinerary (Multi-Day mode)
- Clear all places across all days

### 3. Visual Features

#### Map Markers
- **Single Day**: Purple numbered circles (1, 2, 3, ...)
- **Multi-Day**: Colored circles with day notation (D1-1, D2-1, etc.)
- Markers show on hover with place details

#### Route Lines
- Dotted polylines connect places in order
- Single Day: Purple line
- Multi-Day: Color-coded per day
- Helps visualize the route flow

### 4. PDF Export

#### Export Functionality
- Click "Export to PDF" button to generate itinerary document
- Available when at least one place is added

#### PDF Structure
- **Header**: City name and generation date
- **Single Day PDF**:
  - Lists all places with numbers
  - Shows descriptions (if available)
  - Total place count

- **Multi-Day PDF**:
  - Organized by days with colored headers
  - Each day's places listed sequentially
  - Individual day summaries
  - Total summary across all days

- **Footer**: "Generated by TravelWithDevang"

#### File Naming
- Format: `{CityName}_Itinerary_{Date}.pdf`
- Example: `Dublin_Itinerary_2025-12-22.pdf`

## How to Use

### Single Day Trip
1. Open the Trip Planner panel
2. Ensure "Single Day Trip" mode is selected
3. Click on map markers and select "Add to Trip Plan"
4. Places appear in the itinerary list numbered 1, 2, 3...
5. Reorder by removing and re-adding if needed
6. Click "Export to PDF" when ready

### Multi-Day Trip
1. Open the Trip Planner panel
2. Select "Multi-Day Trip" mode
3. Choose number of days (1-7)
4. Select Day 1 tab
5. Click on map markers to add places to Day 1
6. Switch to Day 2, Day 3, etc., and repeat
7. Each day shows its place count on the tab
8. Review all days before exporting
9. Click "Export to PDF" to generate complete itinerary

### Tips
- Places are added to the currently selected day in Multi-Day mode
- Switch between days to organize your trip chronologically
- Use different colors to distinguish between days on the map
- Export creates a professional PDF document you can print or share
- Clear individual items or entire days as needed

## Technical Details

### Dependencies
- `jspdf` - PDF generation
- `html2canvas` - Not used currently but available for future features
- `leaflet` - Map rendering
- `lucide-react` - Icons

### State Management
- `tripMode`: Current mode (single/daywise)
- `numberOfDays`: Total days for multi-day trips
- `selectedDay`: Currently active day in multi-day mode
- `tripItinerary`: Array of places for single day
- `dayWiseItinerary`: Object with day numbers as keys, place arrays as values

### Map Integration
- Markers automatically update when itinerary changes
- Polylines drawn using Leaflet
- Custom divIcon markers with HTML/CSS styling
- Color coordination between UI and map
